# Barishal Board HSC Result

A simple single-page app to check HSC results from the Barishal Education Board result API.

## How to use

1. Open `index.html` in a browser (or via GitHub Pages).
2. Enter the 10-digit Registration Number and 6-digit Roll Number.
3. Click **Check Result** — the result is fetched live from `resultapi.barisalboard.gov.bd`.

## Features

- Official Barishal Board logo
- Live API lookup (registration + roll)
- Student details: name, parents, institute, EIIN, session, board, group
- Subject-wise marks and grades table, failed subjects highlighted
- GPA badge (green for pass, red for fail)
- Print result + check another result
- No server, no tracking — one HTML file

## Note

This is an unofficial tool built on the board's public result API. Always verify important results with the official result portal.
